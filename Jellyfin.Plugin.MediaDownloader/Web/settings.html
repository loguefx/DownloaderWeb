This plugin forwards download requests to the Media Downloader engine (the headless app running on the Windows PC behind the VPN). The engine URL and key below live only on this Jellyfin server - your browser never talks to the engine directly.

Connection

Base URL of the engine HTTP API (the Windows PC). Port 7878 by default.
The apiKey from the engine's engine.json. Sent to the engine as a Bearer token; never shown to the browser.

Libraries & defaults

Pick which Jellyfin library each kind is filed into. A job is delivered to that library's current drive folders, so adding a drive in Jellyfin is all that is needed.

Verify drives

Asks the engine to check each library's drive folders: are they mounted, writable, and does a real write + read-back succeed? Run this after you mount the drives on the Windows PC (same letters as the Jellyfin server) to confirm finished files will land in the right place.
