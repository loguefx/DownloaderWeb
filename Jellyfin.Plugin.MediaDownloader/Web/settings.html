Settings

Where the engine is, where files go, and the defaults for new downloads.

Download engine

The DownloaderWeb engine does the searching, source detection, downloading and verifying. The URL and key stay on this Jellyfin server; your browser never talks to the engine directly.

Libraries and defaults

Which Jellyfin library each kind is filed into. A job goes to that library's current folders, so adding a drive in Jellyfin is all that is needed. You can still pick another library per title.

Libraries and drives

The engine checks each library folder: mounted, writable, and a real write + read-back. Each folder gets an empty .mediadownloader marker so a dropped mount is never written to.

Engine storage

Stored in the engine's own engine.json and edited here while the engine is online.

When the engine PC sees a library folder under another path (e.g. /mnt/disk1/tv → Z:\tv). Longest prefix wins.

File naming

Files are named exactly like the web downloader, so libraries built by either stay in step. This is not a setting.
